# Bahasa (EN / MS) dalam WaKira

Pengguna memilih bahasa di **Lagi > Tetapan > Bahasa** (dan semasa daftar). Apa yang dilihat pengguna mesti 100% satu bahasa, tiada rojak.

## Tambah teks baharu
1. Letak kunci dalam `src/i18n/en/<ns>.ts` DAN `src/i18n/ms/<ns>.ts` (ns: `common`, `auth`, `home`, `tx`, `acct`, `plan`, `more`). Kunci mesti bermula dengan `<ns>.`
2. Dalam komponen: `const { t, tp } = useT();` lalu `t('home.title')`, `t('tx.saved', { name })`, `tp('tx.items', n)` (kunci `tx.items.one` / `tx.items.other`).
3. Dalam fungsi biasa (utils): `import { t } from '@/i18n'` dan panggil semasa fungsi dijalankan, bukan pada peringkat modul.
4. Bulan/hari/tarikh: `@/i18n/format`. Nama kategori/subkategori/akaun yang dicipta aplikasi: `categoryName`, `subcategoryName`, `accountName` dari `@/i18n/data`.
5. Tidak mahu diterjemah (nama jenama dll.): tulis `// i18n-ignore` pada baris itu.

Fail `ms/*.ts` ditaip terhadap `en/*.ts`, jadi kunci Melayu yang tertinggal ialah ralat TypeScript.

## Pantau (pembangun / admin)
`npm run i18n:audit` melaporkan:
- teks yang ditulis terus dalam skrin (belum diterjemah)
- kunci EN/MS yang tidak sepadan, pemegang tempat `{x}` yang berbeza, pasangan `.one`/`.other` tidak lengkap, kunci berganda
- "rojak": perkataan Inggeris dalam teks Melayu dan sebaliknya (senarai perkataan heuristik; nama jenama dibenarkan)

Pilihan: `-- --files "src/app/(auth)"` (satu kawasan), `-- --json` (untuk alat lain). Keluar dengan kod 1 jika ada isu, jadi boleh dipasang dalam pre-commit atau CI.
Dalam mod dev, kunci yang tiada dilog sebagai `[i18n] missing ...` dalam konsol Metro.
